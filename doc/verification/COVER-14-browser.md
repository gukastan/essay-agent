# COVER-14 / F3 — 실제 브라우저 사용자 흐름 검증

판정: 통과. Root가 Computer Use로 실제 Vue 화면을 조작해 입력, 여섯 단계 진행, 결과4종, 복사, 후속 보완, 버전 조회, 새로고침과 실패 표시를 확인했다. 실제 OpenAI 생성과 결정적 fake 실패 주입을 아래에서 구분한다. 실제 키는 서버가 로컬 설정에서 읽었고 화면/도구 출력/커밋에 노출하지 않았다.

## 실제 OpenAI 관찰

최종 기본 모델은 FAST/QUALITY 모두 gpt-4o다. 초기 FAST gpt-4o-mini 비교에서는 인용/참조 계약 실패로 짧은 경험을 쓰지 못하는 결과를 관찰했다. 모델 기본값 변경과 좁은 계약/prompt 보완 후 최종 빈 입력 및 아이스팩 사례를 다시 실행했다. 모든 입력은 검증용 가상 사례다.

| 실제 화면 조작 | 관찰한 결과 |
| --- | --- |
| 문항·경험을 포함한 입력을 전부 비워 작성 |120자 일반 협업/소통 본문, 소제목·구조 설명·보완 제안 제공, 여섯 단계 완료, 저장됨. non_personalized/확인 필요 표시. 질문만 남거나 빈칸 양식, 자소서 작성 요령으로 대체되지 않음 |

| 원문 보완에서 실제 배움/후속 행동 추가 후 새 버전 작성 |제공한 배움이 새 원문 사실로 반영됨.439자 본문/464자 복사문, 저장된 같은 버전으로 새로고침 복원. fallback으로 사실 문장이 반복돼 낮은 품질임을 확인했으며 매끄러운 완성본으로 판정하지 않음 |
| 아이스팩 설치·수거·세척·시장 전달 두 문장 입력 |본문57자는 제공한 두 문장과 정확히 같음. 제목은 ‘아이스팩 수거함 설치 경험’. 제공되지 않은 초기 목표·어려움은 본문 밖 제안. 이웃 참여 유도나 감정·배움의 추가 없음 |
| 아이스팩 결과의 제출용 복사 |제목+두 줄바꿈+본문과 클립보드 문자열 일치. 결과 저장과 품질 상태를 별도로 표시 |

초기 실패 출력도 보존했다. 수정 전 빈 입력은 자소서 작성 요령으로 흐르고, 아이스팩 출력은 이웃 참여 유도라는 미제공 효과를 추가했다. 좁은 정책 보완 후 위 최종 사례로 다시 확인했다. 최종 성공을 과거 실패가 없었다는 의미로 사용하지 않는다.

## fake 서버를 사용한 실제 UI 실패·상태 검증

COVER-9에서 같은 제품 화면과 실제 proxy/backend/MCP/SQLite에 fake adapter만 주입해 다음을 직접 조작했다.

- 빈 입력 결과4종, 단계 표시, 저장 조회와 복사. 제목 금지 조건에서는 참고 제목만 화면에 표시하고 본문124자만 복사했다.
- 경험2개와 생각/가치관·기업 자료를 별도로 입력해 원본 폼 복원을 확인했다. 보완 선택만으로는 생성되지 않으며, 새 버전 작성 버튼을 눌러야 실행된다.
- unavailable 답변 뒤 문체만 바꾼 새 버전에서 같은 질문을 재요구하지 않았다. 새로고침으로 최신 버전을 복원하고 과거 버전도 선택했다.
- 저장 실패 시 결과와 복사는 유지되고 별도 경고를 표시했다. 조회의 interrupted 상태가 무한 진행으로 남지 않았다.
- 느린 생성 중 새로고침 후 GET의 running을 확인하고, 이후 저장 결과 조회로 completed를 확인했다. 실제 공개 GET 결과와 화면/복사문을 대조했다.
- backend 중단으로503 발생 시 기존 초안을 유지했다. 같은 DB로 서버를 재시작하고 저장 결과를 다시 불러왔다.
- 모바일390, 태블릿820, 데스크톱1440, 키보드 focus, reduced-motion 및 OS light 환경에서 승인된 dark 디자인을 확인했다.

강제 프로세스 종료 뒤 orphan 복구는 별도 실제 프로세스 자동 검사로 증명했다. 정상 종료가 진행 중 초안을 완료시킬 수 있으므로 이를 강제 종료 증거로 부르지 않는다.422/409 전달 및 분할 UTF-8/SSE parser는 실제 proxy/Node 자동 검사 증거이며, UI에서 잘못된 UUID를 강제로 제출한 것으로 주장하지 않는다.
