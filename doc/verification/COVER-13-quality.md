# COVER-13 / F2 — 코드 품질과 오류·재시도 정책 검토

판정: 통과. 최종 코드의 상태 인계, 참조 불변성, 검토/선택본 버전, 수정과 provider 시도 예산, 비동기 실행, SQLite 트랜잭션, proxy 오류 및 종료 처리를 검토했다. 완료를 막는 미해결 코드 결함은 발견하지 않았다. 생성 모델의 의미 판단과 대체 초안 품질 한계는 아래에 별도로 기록한다.

## 검토한 동작

`agent/graph.py`는 분석→구조→부분작성→통합→검토를 연결하고, 검토가 확정한 review_control에 따라 수정 또는 전달로 이동한다. `review_selection.control_for`는 실패·2회 한도·개선 없음·현재 수정 대상 유무를 판정한다. 수정 실패도 한 번으로 계수하고, 실패 후 검토 경유는 새 모델 호출 없이 마지막 일치하는 초안/검토를 사용한다. 실제 SSE trace를 JSON data 이벤트로 파싱해 완료 노드6/8/10, FinalResult1개, 비어 있지 않은 본문을 확인했다.

원문·분석·개요는 현재 근거 버전으로 고정한다. 잘못된 source/fact ID, 종류, 버전, 모호한 인용은 거부한다. 위치 보정은 선언된 현재 source 안의 유일한 정확 인용 일치에 한정한다. 정신적 주장(stated_view)은 사용 가능한 현재 지원자 stated_view 사실을 필요로 한다. 이 검사는 모델이 올바른 유형으로 분류했다는 조건을 가지며 의미의 외부 진위를 증명하지 않는다.

`agent/stage_delivery.py`와 결과 계약 검사는 선택된 같은 버전의 초안/검토에서 본문, 복사문, 실측, 구조와 제안을 조립한다. 새 모델 호출은 없다. 지원 근거가 제거되면 버전·개인화·위치도 갱신하고, 검토가 완전하지 않으면 불완전 상태를 표시한다. 제목 문제로 유효 본문 전체를 폐기하지 않는다.

`agent/openai_llm.py` 및 재시도 경계는 논리 호출당 최대2회 시도를 적용한다. 기술/형식 오류 회복과 5단계의 자동 수정은 별도 예산이다. 불완전·인증·거절·취소처럼 재시도하지 않는 오류도 단계 대체 경로로 전달한다. 기본5개 논리 호출, 성공적인 수정2회까지 최대9개 논리 호출/18회 provider 시도이며, 오류 종료는 더 적다.

서버 lifespan이 모델·MCP·저장소와 실행 task를 소유한다. SSE 구독자 연결과 생성 실행을 분리하고 GET으로 저장 결과를 조회한다. 같은 활성 요청 재전송은409, 완료 요청 재전송은 모델 호출 없이 기존 결과다. 실행 예약·버전 저장은 SQLite 트랜잭션을 사용한다. 재시작 시 고아 실행을 interrupted로 표시하며 자동 재생성하지 않는다. 저장 실패/미확정은 초안 성공과 별도 상태이고, 기술 오류 때 기존 저장 초안을 보존한다. proxy는 upstream HTTP 오류를 유지한다.

211개 export 소스와21개 고정 변경 파일이 기준 Git+snapshot과 일치했다. 이전262개 이력 blob과 공개 후보의 credential/private-trace 패턴 검사에서 발견0건이었다. 초기 scanner의 task- 문자열 오탐은 토큰 경계 수정 후 전체 재검사했으며 실패 기록도 보존했다. 실제 `.env`는 검사 입력에 포함하지 않았다. export 프로세스34개와 통합 프로세스32개 기록에서 소유 프로세스 종료를 확인했다.

## 관찰된 한계

실제 모델이 계약을 반복해서 어기면 마지막 유효 초안 또는 일반 문장을 전달한다. 실제 보완 사례에서는439자 결과에 사실 문장 중복이 남았다. 검토의 정신적 주장 오분류도 초기 시도에서 관찰했으며 이후 근거 유형 검사와 prompt를 보강했다. 최종 사례의 개선을 모든 입력에 대한 의미 정확도 보증으로 확대하지 않는다. 사용자는 본문과 불완전/보완 안내를 보고 다음 행동을 선택할 수 있다.

근거는 로컬 `task-10.xml`, `git-COVER-11-tests.xml`, `task-10-combined-root.xml`, `git-COVER-11-delta-tests.xml`, `git-COVER-11-prepublication-receipt.md`, `git-COVER-11-delta-receipt.md`, `final-root-trace-audit.json`에 보존했다. 원시 실행/모델 캡처는 공개하지 않는다.
