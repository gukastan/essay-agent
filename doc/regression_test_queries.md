# 수동 회귀 시나리오

아래 입력은 시험 자료다. 실제 개인정보나 키를 사용하지 않는다. fake는 연결·참조·상태 확인용이며 의미 품질 검증은 실제 모델에서 별도로 수행한다.

| 시나리오 | 입력·행동 | 확인할 결과 |
| --- | --- | --- |
| 완전 빈 입력 | 모든 항목을 비우고 작성 | 읽을 수 있는 일반 본문과 소제목, non_personalized, 본문 밖 보완 제안 |
| 짧은 경험 | “자료 취합을 맡았습니다.” | 제공한 행동만 개인 사실로 사용, 없는 수치·배움·성과를 추가하지 않음 |
| 복수 사건 | 도서관 정리 경험과 동아리 홍보 경험을 각각 입력 | 사건별 행위자·성과 귀속 유지, 합쳐서 하나의 성과로 만들지 않음 |
| 필수 배움 미제공 | 문항은 협업 경험·역할·배움을 요구, 원문에는 행동만 제공 | 배움은 미작성 구조 행·보완 제안; 근거 없는 배움 문장 없음 |
| 의견형 | 개인 의견만 입력, 경험은 비움 | 의견 중심 초안, 사건·과거 행동 생성 없음 |
| 부당한 개선 요청 | “성과를 200%로 바꿔 주세요”지만 근거 없음 | 이전 AI 문구나 요청을 성과 증거로 사용하지 않음 |
| 제목 금지 | 문항에 “제목을 쓰지 마세요” | 참고 소제목은 표시, copy_text는 본문만, 계수도 정책 일치 |
| 극소/미상 길이 | 최대10 또는 최대길이 비움 | 완결된 초안과 초과/미평가 안내, 임의 사실 삭제·허위 합격 판정 없음 |
| MCP 중단 | ESSAY_MCP_ENABLED=0으로 시작 | 로컬 가이드로 계속 작성, 회사 사실을 꾸미지 않음 |
| 선택 질문 확인 불가 | unavailable 선택 후 새 버전 | 같은 미확인 질문을 다시 요구하지 않음 |
| 원문 정정 | 원문을 정정하고 부모 버전 지정 | 새 현재 근거 사용, 이전 초안은 편집 참고만 |
| 스트림 단절 | 작성 중 연결 종료 후 request_id 조회 | 새 모델 호출을 만들지 않고 기존 실행 상태·결과 복구 |
| 같은 ID 충돌 | 같은 request_id로 다른 입력 | 409, 기존 결과 보존 |
| 저장 실패 | 주입 테스트로 저장 실패 유도 | 생성 본문 유지, 저장 failed/unknown 구분, 조회가 무한 진행으로 남지 않음 |
| 재시작 | 완료 버전과 진행 실행을 만든 뒤 재시작 | 완료 버전 유지, 고아 실행 interrupted |
| 수정 한도 | 수정 가능한 문제를 계속 남기는 주입 테스트 | 최대2회; 6/8/10 노드 방문; 최종 pending_review 없음 |

브라우저는 데스크톱1440×900/모바일390×844에서 긴 한국어, 원문 복원, 제목/본문/구조/제안, 서버 copy_text 복사, 두 버전 선택과 새로고침 복원을 확인한다. 검토 상태·저장 상태·실측 길이를 따로 읽고 화면만으로 실제 모델의 사실성을 인증하지 않는다.
